# Spec Delta

## Purpose

使完整便携包在隔离内网中完成首次配置、启动、模型交互和后续会话恢复，同时避免客户端隐式依赖公共服务，并使离线升级保留用户配置、凭证和既有会话，不影响现有在线分发的默认行为。

## ADDED Requirements

### Requirement: 本地初始化与持久化

离线启动 SHALL 仅使用包内文件初始化独立 DSH profile，通过既有 DSH 服务管理模型与会话，并使用可写用户数据目录。再次启动或升级 MUST 保留用户配置、凭证和会话。

#### Scenario: 无用户缓存
- **WHEN** 用户首次运行离线包且用户目录中无 DSH profile 或运行缓存
- **THEN** 初始化完成且不调用联网包安装流程

#### Scenario: 升级后恢复
- **WHEN** 解压新版本并从原离线用户数据目录启动
- **THEN** 自定义端点、用户 patch 和会话得到保留；需要数据迁移时先明确告知并保留可恢复备份

### Requirement: 内网模型显式配置

离线包 SHALL 允许配置兼容协议、内网端点、模型 ID 和凭证。配置缺失或端点失败 MUST 给出明确诊断，且 MUST NOT 自动回退到公网模型服务。

#### Scenario: 内网流式工具调用
- **WHEN** 用户配置经验证兼容的内网端点并提交需要工具调用的请求
- **THEN** 客户端显示流式响应，完成工具调用及结果回传，并可在重启后恢复会话

#### Scenario: 缺失或失败的模型配置
- **WHEN** 未提供模型配置，或服务不可达、鉴权失败、协议不兼容
- **THEN** 用户收到配置引导或具体错误，且无隐式公网回退，日志不暴露密钥

### Requirement: 无隐式公网依赖

离线模式 SHALL 在自动更新检查、插件目录刷新、公共模型发现和遥测发起请求之前阻止这些自动公网动作。手动在线更新或安装入口 SHALL 提示离线交付方式。普通在线模式的既有默认行为 MUST 保留。

#### Scenario: 仅放行内网模型服务
- **WHEN** 运行环境只放行已配置的内网服务并监测网络访问
- **THEN** 启动、对话、工具执行和恢复不触发上述自动公网请求，也不依赖失败超时后继续运行

#### Scenario: 手动更新
- **WHEN** 离线模式下调用更新或在线插件安装入口
- **THEN** 在下载前说明离线限制和替换完整包的方法，不启动包管理器

### Requirement: 真实离线验收

每个声明支持的目标 SHALL 在无开发依赖和缓存、阻断公网的环境验收，并报告模型服务使用的是本地模拟还是实际内网端点。验收 MUST 包括真实交互终端的启动、取消、正常退出与会话恢复。

#### Scenario: 目标平台交互测试
- **WHEN** 在目标平台 inline、fullscreen 和窄终端中执行启动、输入、resize、取消及退出
- **THEN** 终端状态正确恢复，会话可恢复，并记录平台和测试结果

#### Scenario: 无真实内网访问条件
- **WHEN** 构建环境只能访问本地模拟模型服务
- **THEN** 报告仅标记模拟协议测试通过，真实内网集成保持待验收
